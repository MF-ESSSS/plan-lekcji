# Plan lekcji

Небольшое Android-приложение с расписанием на польском языке. Работает без интернета и получает обновления интерфейса и расписания из этого репозитория при открытии и возвращении в приложение (не чаще одного раза в минуту). Веб-интерфейс не обращается к внешним сайтам; обновления скачивает Android-оболочка по HTTPS.

## Обновление расписания и дизайна

1. Изменить файлы в `dist/`: `app.js` — расписание и логика; `style.css` — оформление; `index.html` — разметка.
2. На компьютере, где хранятся ключи, выполнить в PowerShell: `./scripts/publish-update.ps1 -Publish`.
3. Открыть приложение с интернетом. Новая версия загрузится и сохранится для работы офлайн. Если версия не изменилась, интерфейс не перезагружается. GitHub может отдавать закэшированный манифест около пяти минут после публикации; после этого повторное открытие приложения получит обновление.

Обновление представляет собой полный архив трёх файлов и манифест с возрастающим номером версии, SHA-256 и подписью RSA. Приложение проверяет подпись, размер, хеш и состав архива перед переключением. При сетевой ошибке используется предыдущая копия; при первой установке — файлы, встроенные в APK. Публичный ключ встроен в приложение. Закрытые ключи и пароли в репозиторий не входят.

## APK

Версия 1.2 впервые включает загрузчик обновлений. Её нужно установить один раз поверх предыдущего приложения. Изменения Android-оболочки и разрешений в будущем потребуют нового APK; расписание, HTML, CSS и JavaScript обновляются без установки APK.

Локальная сборка: `./android/build.ps1`. Инструменты сборки и ключи находятся отдельно от репозитория в `C:\Users\Pawel\Downloads\chaos-android-build`. Ключи нужно сохранять для следующих обновлений и сборок.

Данные расписания опубликованы с разрешения владельца. Заполнены понедельник–пятница по предоставленным скриншотам. У последнего урока вторника время не предоставлено; у первого урока пятницы не указан кабинет.

## Личные изменения

Три быстрых нажатия (в течение секунды) по одному пустому месту открывают редактор. Выбрать день недели, удалить ненужные уроки через `Usuń` или добавить предмет, начало, конец и кабинет через `Dodaj lekcję`. Нажать `Zapisz dzień`. `Anuluj` закрывает окно без сохранения. Личные изменения действуют каждую неделю и хранятся только на текущем устройстве; в GitHub не отправляются и новыми веб-обновлениями не заменяются. Пустой список уроков тоже сохраняется.

Для совместимости с уже установленным APK 1.2 сохраняются собственные cookie приложения, с резервной копией в localStorage при его доступности. Новая Android-оболочка для этого веб-обновления не требуется. Проверки хранения без DOM storage и данных расписания: `node tests/schedule.test.cjs`.

Имя и фамилия вверху справа меняются нажатием на имя. При первом открытии этой функции показана подсказка `KLIKNIJ IMIĘ, ABY JE ZMIENIĆ!`; после подтверждения она скрывается. Имя сохраняется только на устройстве и не отправляется в репозиторий.

## Счётчик установок — APK 1.3

APK 1.3 создаёт случайный UUID установки в приватной памяти Android. При наличии интернета отправляет только этот UUID на `https://plan-lekcji-counter.ssua.workers.dev/register`. Имя, фамилия, уроки и задания не отправляются. Сервер сохраняет ID и время первой регистрации в отдельной базе D1 `plan-lekcji-installs`. Повторный запрос того же UUID не увеличивает число. После успешного ответа повторные регистрации прекращаются; при ошибке приложение повторяет попытку при возвращении и раз в минуту. Переустановка с удалением данных может считаться новой установкой. Старые запуски версии 1.2 восстановить нельзя.

Чтобы открыть статистику: быстро нажать `Powiadomienia` два раза, затем `Wiadomości` три раза. Между нажатиями — не более 2,5 секунды, вся последовательность — до 10 секунд. Другой порядок сбрасывает последовательность. Экран показывает агрегированное количество, а кнопка `Odśwież` запрашивает свежие данные. Жест скрывает вход в окно, но не является серверной авторизацией: `/stats` возвращает только общее число, без списка ID.

Для этой функции нужен APK 1.3 поверх старого; последующие изменения веб-интерфейса продолжают приходить через GitHub. Оболочка не подставляет веб-кэш старше встроенной версии 15. Код сервера и конфигурация D1 находятся в `counter/`. Проверка регистрации на настоящем SQLite: `node --test tests/counter-server.test.mjs`. Повторные регистрации тестируются в локальной базе, без добавления тестовых устройств в рабочий счётчик.

## Даты, домашние задания и тесты

Текущая неделя и выбранный день переключаются при смене даты по польскому времени, в том числе в открытом приложении и при возвращении из фона. На выходных показана пятница текущей недели; новая неделя начинается в понедельник. Расписание уроков повторяется по дням недели.

В скрытом редакторе раздел `Prace domowe i sprawdziany` позволяет выбрать конкретную дату, тип, предмет и необязательный текст. Синяя полоса означает домашнее задание, красная — тест. Под датой показаны только существующие типы: одна полоса при одном типе, две при обоих, без полос при отсутствии записей. Под расписанием показаны сами записи с соответствующим цветом. Задания не повторяются автоматически каждую неделю. После изменений нажать `Zapisz zmiany`.
